# Analytics Hub (Streamlit)

A professional landing page that links to my deployed Streamlit portfolio apps.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy (Streamlit Community Cloud)

- Create a GitHub repo from this folder
- Set the Streamlit app entrypoint to `app.py`
